# بنك أسئلة معالجة الصور الرقمية (DIP CCE4130) — مراجعة ليلة الامتحان (78 سؤالاً)

Digital Image Processing Exam Prep — كويز تفاعلي شامل يحتوي على أسئلة الامتحانات والمفردات العلمية وتفسير كل فكرة وشفرة الامتحان.

### المميزات المضافة:
- 💾 **حفظ التقدم التلقائي (Auto-Save):** يحتفظ برقم السؤال الذي وقفت عنده وإجاباتك السابقة تلقائياً في المتصفح.
- ❌ **مراجعة الأخطاء (Review Mistakes):** نافذة مخصصة لمراجعة أي سؤال أخطأت فيه مع الإجابة الصحيحة والتفسير وشفرة الامتحان وإمكانية التدرب على الأسئلة الخاطئة فقط.
- 🔍 **فلاتر الأسئلة:** تصنيف الأسئلة إلى (الكل / الأسئلة المكررة في الامتحانات 🔥 / الأسئلة الفريدة ✨).
- ⚡ **خفيف وسريع:** بدون سيرفر أو متطلبات تشغيل.
